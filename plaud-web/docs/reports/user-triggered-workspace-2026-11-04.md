# 按需下载与本地转写工作台验收

日期：2026-11-04。范围：项目内录音目录、默认 Ogg、用户主动下载与转写、统一录音工作台。ChatGPT 发送延期，未纳入本轮实现。

## 使用方式

打开 <http://localhost:5173/#library>，无需 PLAUD 登录即可使用本机音频。顶部“连接 PLAUD”在弹窗内完成登录、设备选择与连接，工作台始终保留。连接后可查看设备状态和待下载文件。在设置中选择统一转写语言，再选择“下载并转写”或“仅下载 Ogg”。设备开始录音或暂停时暂缓下载；仅连接或发现新文件不会转写。

本机文件通过“导入”菜单选择“导入并转写”或“仅导入音频”。仅保存的录音可播放、改标题，之后单独点击“开始转写”。正文支持时间回听、搜索、校对和历史版本。常用“导出文字”位于详情操作区，格式和版本选项折叠展示。桌面列表与正文分别滚动，播放器和设备状态保持可见。

列表统一展示个人库与当前账号有权访问的录音，可按“全部来源 / 本机导入 / PLAUD 录音”筛选，并记住用户主动选择的来源。底层仍隔离账号数据；本机导入始终进入个人库。设备下载后定位对应录音，已有设备录音复用本地文件。界面显示保存位置，可复制路径。

## 目录与数据

默认位置：`<project>/.local-audio/library/scopes/<scope>/recordings/<recordingId>/`。

- `original/`：原件；新设备录音保存为 `source.bin`。
- `playable/`：成功恢复的设备音频；新录音保存为 `audio.ogg`。
- `transcripts/`、`revisions/`：结构化全文和校对历史。
- `exports/latest.md`、`latest.txt`、`latest.json`：当前完整稿，转写完成或保存校对后自动生成。
- `exports/<revisionId>/`：对应版本的可读文件。
- `jobs/`、`work/`：任务状态与模型阶段缓存。

本机导入保留输入格式。未知设备封装保留原件，不强行制造 Ogg 或送入模型。改标题不移动目录。媒体继续被 Git 忽略，Vite 禁止直接提供私有目录。

本机旧录音库已复制并逐文件 SHA-256 校验：161 个文件，原目录保留。迁移只在默认目标为空时执行，不覆盖已有项目库，拒绝活动旧服务和符号链接。已有四条长短样本均可读取，已补生成可读文件。原有长样本本轮未重新推理。

## 工作台常驻与弹层流程

后续调整将录音工作台设为唯一主界面，包含旧 `#device` 入口。账号恢复在后台执行；无账号或无蓝牙不阻塞本机音频。登录、设备选择和连接进度共用一个原生模态弹窗；设置与诊断使用同一弹层的右侧抽屉形态。关闭弹层不触发断连、取消连接或清空正文，连接成功后仅收起设备弹窗。浏览器原生蓝牙授权仍由用户点击连接后触发。

已连接设备的下拉菜单提供详情、刷新目录、切换和断开，账号菜单提供登录或退出。录音列表合并个人库与当前账号库，所有播放、修改与导出请求继续使用对应录音所属范围。本机导入固定进入个人库；登录恢复不切换当前详情，账号失效或切换会立即清除旧账号内容，保留本机内容。账号列表请求失败时仍显示本机录音。

## 边界

- 本轮已在 Edge 点击真实设备“连接设备”，浏览器配对窗口持续扫描但没有可选设备，已取消扫描并返回录音工作台，因此未完成真实 BLE 下载验收。协议和传输回归、设备下载入库接口及页面意图接线均已验证，设备唤醒并与手机断开后仍需实测。
- 设备源文件上限 256 MiB；录音库每个上传文件上限 1 GiB、时长上限 6 小时。保留 Ogg 不受浏览器 WAV 转换 16 MiB 限制。本机原件恢复上限改为 256 MiB，选 WAV 时仍由转换器执行自身限制并保留 Ogg 回退。
- BLE 续传仍只在当前页面内存中；本地转写由独立服务执行。关闭本地服务会中断任务，下次启动恢复已经由用户发起的任务。
- 自动转写仍为候选稿，人工质量 G0 未通过；此次边界修复不代表文字、人物或时间准确率达标。
