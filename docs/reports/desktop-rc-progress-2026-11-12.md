# RecDock Mac 发布候选版验收记录

日期：2026-11-12。当前版本：`1.0.0-rc.2`。本机核心流程通过，源码、GitHub 预发布附件及官网生产部署已发布。

## 交付边界

用户确认保留既有模型质量和一键发送到 ChatGPT，转为独立 Mac App；后续再做 Windows。用户随后明确暂不提供 Developer ID，先交付可以手动允许打开的候选包。因此本轮结果是 ad-hoc 签名候选版，不是已获 Apple 公证的稳定公开版。没有使用公司证书。

Mac App 不需要公网工作台、网页配对码或网站授权即可导入、处理、回听、校对和导出。关闭窗口后台继续，明确退出停止处理并保留任务。ChatGPT 转发通过用户安装的 Edge 扩展连接已登录的浏览器页面。

## 真实流程验证

1. 候选 App 正常打开，读取原有 12 秒样本、既有文字修改和模型目录。重开同一个包没有重新签名，也未再次要求钥匙串授权。
2. 音频工具和 GPU：最终包内 FFmpeg、FFprobe 返回 0，MLX 返回 `Device(gpu, 0)`，Torch MPS 返回可用。不是仅检查文件是否存在。
3. 6.72 秒专用测试 WAV 实际完成 preparing / transcribing / aligning / diarizing / merging，约 47.7 秒（含模型加载），得到完整一句语音及时间、讲话人。
4. 点击时间回听通过，播放进度到录音末尾。修改标点后单独生成修订，原机器稿保留；未自动标记为已核对。
5. 用同一句测试语音重复四次组成 26.88 秒恢复样本。关闭窗口后任务推进到转写；处理中退出时任务落盘为 interrupted，服务端口释放。重启后同一个任务继续，`attempt=2`、`resumed=true`，完成四段正文。
6. 最终 rc.2 包另行处理 8.72 秒测试 WAV（原测试语音加 2 秒静音），约 42.6 秒含加载完成所有阶段。使用的是包内 Node / Python / 音频工具和固定模型，不依赖源码运行入口。
7. 最终包通过原生保存框导出完整 Markdown，724 字节，SHA-256 为 `b804f3608953e5614c53a4b1bb1bd267ca0c1ab5092cea2a4166d94f181d9952`。全文导出格式的服务器回归已通过；没有把所有格式都说成手动原生保存框逐一验过。
8. Native Messaging 在 Edge 实际连接。先发送既有 12 秒测试稿，再发送新处理并保存的 6.72 秒修订稿，均观察到实际 Markdown 附件、用户提示词、有效对话地址和 ChatGPT 回复中的对应正文时间。第二份附件使用已保存人工修订，不上传音频。
9. 同一份已确认提交的稿件再次点击只打开原对话，仍为一个附件和一条用户消息。长中文全文分块、哈希、缺块与篡改拒绝由桌面测试覆盖。
10. 官网本地桌面和窄窗口视觉检查通过；段落示意切换、时间显示和下载区域锚点通过。界面示意与真实录音清楚区分，没有把演示排版表述为真实处理结果。

录音均为专用测试内容。未发送实际会议录音、其他私人稿件或原始音频。对话地址不进入公开仓库的证据文件。

## 修复与工程实现

- 桌面主进程、受限 preload、独立 Node 服务和 Python Worker 统一管理生命周期；监听 `127.0.0.1:43128`，每次启动独立凭据，保留 CSRF、资料范围隔离及库锁。
- 复用既有资料路径，模型与录音不写入 App bundle。旧助手占用库时给出明确错误；不删除有效锁，不同时运行两个写入者。此前残留旧服务已核对执行路径后正常退出。
- 模型与应用设置提供目录选择、下载、完整校验、环境检查、取消及授权入口。三个固定模型完整校验实际通过。下载令牌只在显式保存 / 使用时访问系统加密存储，状态查询不触发钥匙串；用户选择拒绝后仍能使用既有模型。
- FFmpeg 从固定官方 8.0.1 源码构建，只启用所需音频功能，无外部编解码库。对应源码压缩包、许可、构建脚本和参数随包保留；替换旧 Homebrew 音频依赖并核对动态库路径。
- 模型曾对 26.88 秒音频输出 26.963 秒端点。旧的 40 ms 阈值使合并失败；现按实际波形区间求交，不扩展音频、不重排正文，保留原始模型文件并标记受影响段落 `speaker_uncertain`。原模型和修订未变，流水线版本更新为 `local-paragraph-v3-fixed120-waveform-intersection`。
- 固定 Electron 开发入口复用已允许的运行时，普通源码修改不重签 App。只有最终候选包冻结后重新打包。
- 官方 Electron ZIP 固定 SHA-256；构建从经验证的原助手 ZIP 提取运行时，按标准源码打包提取文件与内部符号链接，不继承浏览器附加的构建输入元数据。未关闭 Gatekeeper 或公司保护。
- 新应用图标、菜单栏图标、文件菜单关闭快捷键、版本和来源说明已打包。

## 保留的限制

- 未进行 Developer ID 签名和 Apple 公证。用户自行按系统提示允许可信候选包；公司管理设备可能另外拦截子进程，无法保证所有策略下可用。
- 未在另一台无开发环境的干净 Mac 完成首次下载、模型许可与安装验收；已有模型路径的校验和离线处理已通过。
- 桌面端 PLAUD 真机连接与长录音回归仍需扩展；本候选版以本机音频导入流程为主要可交付体验，原 Web / Android / iOS 实现保留。
- Windows、Intel、较旧 macOS、睡眠唤醒、Chrome 转发和扩展商店分发尚未验收。Edge 当前使用用户加载的解压缩扩展。
- 首次模型下载的真实新账号授权、断网恢复和磁盘不足尚未在干净设备逐项手测；相应逻辑和回归存在，不把它们冒充干净机器通过。
