# ChatGPT 一键转发交付

## 当前交付范围

从录音详情页发送当前已保存版本的完整 Markdown 转写和设置中的提示词。搜索、讲话人筛选、分页不改变发送范围。历史版本有独立入口文案；未保存编辑不可发送。默认在**同一个已连接的 ChatGPT 标签页**新建对话，转发成功后打开原对话。

工作台始终留在录音工作台；首次安装和绑定位于设置抽屉。发送异常展示原因、连接设置和手动导出入口。已经确认提交的版本不会因重复点击而再次发送。

## 实现与边界

- 后端：沿用本地会话、CSRF 与个人/账号资料隔离；从明确 revision 导出全文，校验源音频哈希，以目标连接、录音版本、内容哈希和提示词哈希去重。发送快照与回执随录音保存。
- 扩展：限定工作台顶层来源；固定一个已有 ChatGPT 标签页、一个运行任务；通过原生文件输入框、富文本编辑器和可见发送按钮操作。提交前持久记录状态。
- 回执：必须观测相同用户消息、实际附件卡和有效对话链接。发送按钮被点击不等于已提交；提交结果未知时不重发。
- 暂停：已有草稿、其他附件、回复未完成、未登录、配额、上传超时、页面改版、目标页面关闭或连接改变，均由用户处理后核对。更换 ChatGPT 账号需要重新连接。
- 文件：自动转发最大 8 MiB，不截断全文。只发送转写资料，不发送原始音频。ChatGPT 自身配额仍适用。
- 此次实现确认单次对话提交；不新增资料空间、跨对话检索、Memory 或远端文件管理。

## 0.1.1 草稿恢复与状态轮询修复

从已有对话切回 ChatGPT 首页时，首页可能恢复此前未发送的草稿。之前扩展会正确停止上传，但只返回“新对话尚未准备好”；同时，轮询又会等待一次 DOM 检查，可能超时并被误报为“未连接扩展”。这与资料空间中是否存在同一文件无关，当前实现不查询资料空间做去重。

修复后，运行中的任务立即返回已保存阶段，页面检查有独立时限；新对话恢复草稿时明确提示处理草稿，并保留内容。暂时取不到回执时只重试状态查询，不重新上传；既有暂停任务再次核对时也会更新具体阻塞原因。扩展版本更新为 0.1.1。

已在 Edge 原有单个 ChatGPT 标签页复现并验证：旧 PLAUD 草稿保持原样，目标访谈稿未上传，工作台显示具体草稿提示。新增首页恢复草稿、页面检查期间轮询响应、回执超时恢复回归；全量 **326/326** 测试与生产构建通过。HTTP 测试使用独立内存会话存储。

## 0.1.2 连续发送与已提交残留清理

真实连续发送复验定位了三个单页导航问题：新聊天会恢复上一条已提交的发送文本；页面保留隐藏的旧编辑器，原来从整个文档取文件输入时可能选中隐藏的图片输入框；页面还保留隐藏消息副本，选中第一份匹配文本可能漏掉可见消息及其附件卡。

修复后，优先点击页面原生“新聊天”并等待编辑器稳定；上传入口严格限定为可见编辑器所属表单内支持 Markdown 的文件控件。对当前连接下已确认提交、内容完全一致且无新增附件的首页发送残留，通过原生编辑器输入事件清理；手动新建聊天后也会检查这种残留。新增文字、用户附件、其他连接和未确认提交的草稿均保留。回执仅使用可见用户消息及其附件，不读取 ChatGPT 私有存储或调用私有接口。

已在同一个 Edge 标签页连续发送两份专用合成转写 A、B，两者分别获得独立对话链接，中间没有手动新建聊天；第二个对话仅有一条用户发送消息。随后验证新聊天输入框为空、手动草稿在刷新后仍被保留。详细回执在本机 `.local-audio/reports/chatgpt-consecutive-smoke.json`。复验未使用真实会议正文。

新增连续双稿发送、已提交残留匹配、手动新草稿保留、隐藏编辑器/图片控件隔离和隐藏消息副本回归；全量 **331/331** 测试、TypeScript 检查与生产构建通过。

## 0.1.3 自动重名附件与有限等待

真实任务中，ChatGPT 为已存在的同名附件添加了 `(1)` 后缀。编辑器与发送按钮已经可用，但旧适配器只接受原始文件名，因而一直停留在附件阶段。现在附件就绪、提交前检查及提交回执采用相同的识别规则：允许数字重名后缀，但文件名中的版本和哈希部分必须一致，并拒绝其他附件或多份附件。

对已上传但尚未点击提交的本工具任务，显式核对时可复用完全匹配的提示词与唯一就绪附件，不重复上传。页面准备、附件就绪和回执确认按经过时间截止，不再因慢速页面检查放大等待次数；进度展示具体阶段与等待原因。

Edge 现场恢复了原有重名附件任务，沿用原任务 ID 和附件，确认一个对话中只有一条用户消息，工作台恢复“已提交”。本机证据为 `.local-audio/reports/chatgpt-renamed-smoke.json`。新增重名显示名、恢复已有附件、额外附件拒绝和超时回归；全量 **335/335** 测试、TypeScript 检查与生产构建通过。
