让网页连接你的 Mac

RecDock 网页提供工作台，本地助手保存录音并运行转写。助手安装包自带处理运行时，模型在首次使用时单独准备。本地测试包尚未完成 Apple Developer ID 签名与公证，不是公开分发版本。

首次连接

  1. 解压测试安装包，将 RecDock.app 放到固定位置并打开。菜单栏出现波形图标后，保持助手运行。
  2. 在助手“模型准备”中选择已有模型并校验，或按引导准备模型。讲话人模型需要你先在 Hugging Face 官方页面获得许可；模型下载令牌仅保存到本机钥匙串。
  3. 从助手点击“打开录音工作台”，在网页点击“连接 Mac 助手”。浏览器请求本机网络访问权限时，按你的意愿允许该工作台访问本地服务。
  4. 在助手“网站授权”中核对完整网站地址，再点击“允许”。只有你批准的网站才能读取和管理本机录音、转写与设备账号。
  5. 导入音频，选择“仅导入音频”或“导入并转写”。本机导入无需登录 PLAUD。

日常使用

桌面确认的网页授权有效期为 30 天，保存在当前浏览器的网站存储中；助手保存对应令牌摘要。后续打开同一工作台可自动恢复，助手重启不要求重新输码。在助手或网页中撤销后立即失效。清除网站数据、到期或更换浏览器后，需要重新授权。

关闭窗口或网页不会停止后台任务；明确退出菜单栏助手才会暂停处理，重新启动后恢复未完成任务。登录后自动启动由你在助手中选择。

Mac 助手默认把资料保存在用户目录 ~/Library/Application Support/RecDock，不会自动移动源码版已有录音。模型和录音不上传到网页托管服务；模型下载、PLAUD 账号验证及你主动选择的云功能仍需联网。

备用配对与开发入口

命令行版和备用连接仍可使用 本机配对码页面。一次性码五分钟有效；此类临时授权只保留在当前标签页，助手重启后需要重新配对。

RECDOCK_WEB_ORIGINS='https://你的实际域名' npm run companion

遇到问题

  • 无法连接：确认菜单栏助手已启动，网页来源与助手配置相同，浏览器允许本机网络访问。
  • 模型不可用：在助手中分别校验模型与检查处理环境。网页连接成功不代表模型或 Metal 已就绪。
  • 服务启动失败：先关闭旧的命令行助手，避免占用同一个服务端口。
  • 首次测试安装包应放到固定位置；公开下载版的签名、公证和更新机制将另行提供。
  • 卸载：关闭登录后自动启动，退出助手后移除 App。录音与模型保留，不会随 App 自动删除。
  • 蓝牙设备仍需 Chrome / Edge 的 Web Bluetooth 权限；更换网页来源后需重新授权。ChatGPT 扩展目前仍受其已有来源配置限制。
