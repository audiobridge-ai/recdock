# 录音工作台交付与验收说明

日期：2026-11-04。结论：本轮已完成正式工作台中的本地录音库、后台处理、候选全文核对及完整导出，可以进行功能验收。模型结果仍需回听，人工质量 Gate G0 未通过；本报告不宣称文字、人物或边界准确率达标。

## 打开与验收

正式入口：<http://localhost:5173/#library>。本机服务已启动，Edge 已打开中文长录音。原 `127.0.0.1:8766` 页面是上一阶段的独立实验核对页，日常使用请进入正式工作台。

建议按以下顺序验收：

1. 在左侧选择中文周会或英文访谈。正文按“讲话人、时间、文本段落”排列；每页 60 段，可以搜索、按讲话人筛选、只看有疑问或未核对段落。
2. 点击一段的时间，确认播放器跳到对应位置；使用倍速、前后 5 秒和“跟随播放”。展开“讲话人 · 试听与修改名称”，听取代表片段后再命名。
3. 点击“编辑”，修改文字、讲话人或起止时间，点击“保存本段”。刷新后检查修改仍存在；在“稿件版本”中查看原始机器稿和历史稿。历史稿只读。只有实际回听确认后才勾选“已核对”。
4. 即使搜索只剩一段，点击“导出当前完整版本”也应获得整条录音。Markdown 适合上传 ChatGPT，TXT 为纯文本，JSON 包含结构与核对状态，SRT/VTT 用作候选字幕。
5. 从本机再导入一条录音并选择语言，观察排队与真实阶段。可以关闭浏览器页面；本地 Node 服务保持运行时处理继续。相同原件再次导入应复用既有录音。

后续在 ChatGPT 原生页面上传导出的 Markdown，提问时明确给出文件名，并要求检索来源、引用讲话人和时间。此前英文全文的跨聊天验证见[上一阶段报告](audio-review-2026-11-03.md#chatgpt-网页与跨聊天验证)。本轮没有再次上传，也没有把全文写入 Memory。

## 实现行为

- 个人资料入口不要求登录 PLAUD 或连接蓝牙。当前账号资料由本机会话决定，与个人及其他账号范围隔离。退出账号暂停该范围任务并隐藏资料，不删除录音。
- 流式上传原件，限制单文件 1 GiB、6 小时；使用 FFprobe 和完整 FFmpeg 解码检查。未上传完整的文件不进入录音列表。暂不能恢复的设备原件保留为待恢复状态，不送模型。
- BLE 完整下载后交付原始设备字节和可播放副本，分别保存来源哈希。转写 Worker 不接收 RSA 私钥。此次实现已接线并通过既有协议回归，尚未重新连接真机下载验证。
- 一次只运行一个模型任务。Node 持久队列启动独立 Python Worker，按准备、转写、对齐、区分讲话人和合并依次执行；模型逐阶段卸载。模型已准备后处理使用本地文件，不调用 OpenAI API。
- 任务保存实际阶段、已完成块与心跳。失败重试创建新任务并复用相同指纹的有效阶段；源资产、语言、模型锁、设备或关键 Python 源码变化会更换处理指纹。
- 关闭网页不终止服务任务。服务停止会终止 Worker 进程组；重启后个人未完任务恢复，账号任务等待该账号的有效会话恢复。显式取消的任务不会因重启自动重跑。
- 校对保存为服务器端不可变版本，使用原子文件和乐观锁。其他页面已更新时返回冲突，保留当前输入。原始机器稿、历史正文和对应核对状态分别保留。
- 改文字或时间清除旧字词时间并标注待核对，不把旧词级结果套到新文本。当前没有自动局部重新对齐；保留可手工修订的句段范围。
- 导出读取所选完整 revision，不读取当前分页或筛选结果；文件包含来源哈希与版本。JSON 保留完整结构。SRT/VTT 按原时段输出并保留重叠，重叠段附提示；它们是候选字幕，播放器对重叠显示可能不同。
- 删除是本机回收站，可恢复原件与稿件，会取消未完任务；当前不提供永久清理，不释放占用空间，也不会删除 ChatGPT 已上传副本。

## 本地数据与恢复

默认媒体库：`~/Library/Application Support/PLAUD BLE Workspace/library-v1/`。原件、处理阶段、稿件与历史保存在当前本机用户目录中，目录权限 0700、文件 0600；本轮不额外加密媒体。它不依赖浏览器 localStorage。需备份时停止本地服务后复制完整媒体库，避免仅复制当前稿件遗漏原件和历史。

开发服务的启动方式：

```sh
cd /path/to/recdock
npm run dev
```

随后打开 <http://localhost:5173/#library>。本机模型和 Python 环境已准备，不需重复下载。运行时不需要 Hugging Face token；首次模型下载与授权说明保留在[本机基准文档](../audio-benchmark.md)。同一媒体库只允许一个服务实例，避免同时启动 dev、preview 或迁移 CLI。

## 明确保留的后续工作

1. 建立人工文字、人物和时间参考，测量 CER/WER、DER 与边界偏差，完成质量门槛。此前零时长词比例约中文 7.8%、英文 33.2% 仍是对齐缺陷，不能解释为文字错误率。正式 UI 采用句段候选范围并保留疑问标记。
2. 改善对齐、VAD 与切块接缝策略，增加局部修改后的自动重对齐。当前继续采用已测的 120 秒基线。
3. 使用真实 PLAUD 设备验收完整下载后的自动入库、原件及恢复副本保留、自动排队。
4. 浏览器扩展、一键发送 ChatGPT、远端同步回执、自动分卷及媒体永久清理另行实现。当前通过完整 Markdown 导出和 ChatGPT 原生上传完成资料接入。

这轮可以验收“导入到核对和导出”的功能链路；准确率和真实设备新增接入行为需按以上边界继续验收。
