## 验收结论与后续迭代

1. **真实设备完整验收通过，依据为用户实测确认。** 不再要求重复该验收才能开始 App 开发；用户未提供的设备和固件信息不作补写。
2. **当前转写质量验收通过，依据为用户确认符合预期。** 原计划 G0 的量化评分未补做，不虚报 CER/WER、DER 或时间偏差达标。此前长音频无效词时间比例约中文 7.8%、英文 33.2%，仅作后续优化参考，不作为开发阻塞项。固定 120 秒切块、VAD/接缝优化、自动局部重对齐等按用户反馈持续迭代。
3. **设备和运行环境有限定。** 自动认证准备支持传统协议与协议 20；协议 30 在 `server/cloud-client.ts` 明确返回 `UNSUPPORTED_AUTO_ECC`，需已有 ECC 手工凭据。完整工作流目前面向 macOS；BLE 中断进度只在当前页面内存，刷新或关闭后不保留。
4. **部分增强能力未实现或未验收。** 模型下载使用独立准备工具；自动分卷、媒体永久清理、讲话人数上下界页面配置尚未实现。Chrome 真实 ChatGPT 账号流程和移动设备页面未验收。扩展的 `submitted` 只证明该对话提交；自动资料空间持久化、跨对话检索与 Memory 不在此次扩展交付内，英文全文此前的独立原生检索实验另有记录。
5. **完整官方 App 功能不在当前 Web 范围。** 新设备绑定/解绑、录音开始/停止控制、设备文件删除、OTA 与 Wi-Fi 传输均被 README 明确排除。若 App 要覆盖这些能力，需要新增需求和验证，不能由 Web 已有能力推定完成。
